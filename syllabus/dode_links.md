# Dode links

Dit bestand houdt bij welke links in de syllabus gecontroleerd moeten worden op dode links (404's, verwijderde pagina's, etc.).

## Installatie en gebruik

We gebruiken de tool [`markdown-link-check`](https://github.com/tcort/markdown-link-check). Je hebt [Node.js](https://nodejs.org/) nodig (inclusief `npx`, dat standaard meekomt).

Installatie is niet nodig: `npx` downloadt de tool automatisch bij de eerste keer draaien.

**Eén bestand checken:**

```bash
npx markdown-link-check syllabus/onderwerpen/ai_kunst.md
```

**Alle markdown-bestanden in de syllabus checken:**

```bash
find syllabus -name "*.md" -exec npx markdown-link-check {} \;
```

De tool geeft per link een `✓` (werkt) of `✖` (dood, of geblokkeerd) met de HTTP-statuscode. Let op: een `403`- of `429`-status (en soms status `0`) betekent niet altijd dat een link écht dood is — sommige sites (bijvoorbeeld decorrespondent.nl) blokkeren geautomatiseerde checks. Controleer zulke links handmatig in de browser voor je ze aanpast.
